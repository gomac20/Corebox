승인된 계획서 `spec.md`를 그대로 구현한다. 계획에 없는 기능을 추가하지 않는다.

- `D:\OneDrive\Desktop\클로드실습\클로드코드\블로그만들기실습\CLAUDE.md`의 "웹앱 규칙"

## 사용자 결정 (승인됨)
- 새 타일 확률: 2는 90%, 4는 10%
- 2048 달성 후 "계속하기" 제공
- 앱 색: 고전 2048 색(베이지·주황 계열). 블로그 테마와 무관하게 앱 자체 CSS 변수로 정의
- 이동 애니메이션: 간단한 CSS transition (`prefers-reduced-motion`이면 끔)

## 만들 파일 (이 폴더 안에서만)
`D:\OneDrive\Desktop\클로드실습\클로드코드\블로그만들기실습\apps\2048\`
- `index.html`, `style.css`, `game.js`, `app.js`

## 구현 요구사항
- 순수 HTML/CSS/JavaScript. 외부 라이브러리·CDN 사용하지 않는다. `app.js`는 ES module로 `game.js`를 import한다.
- `game.js`는 DOM을 다루지 않는 순수 로직이며, `slideLine`을 export한다. 한 이동에서 이중 합치기가 없어야 한다.
- 방향키로 이동하고 `preventDefault`로 페이지 스크롤을 막는다. 스와이프(임계값 약 30px)를 지원한다.
- 점수판: 현재 점수, 최고 점수. 최고 점수는 localStorage에 저장하되 모든 접근을 try/catch로 감싸고 실패해도 동작한다.
- 새 게임 버튼, 승리 오버레이("계속하기", "새 게임"), 게임 오버 오버레이("다시 시작").
- 보드가 바뀐 이동에서만 새 타일을 생성한다.
- 모바일: viewport meta, `lang="ko"`, 버튼 최소 44×44px, 가로 스크롤 없음, 보드 위 `touch-action: none`, 375/768/1280px에서 정상.
- 접근성: 보드 `aria-label`, 점수 영역 `aria-live`, 버튼 포커스 표시.
- 코드 주석은 한국어, 변수·함수 이름은 영어. HTML 들여쓰기 2칸.
- 이 앱은 `apps/2048/` 밖의 어떤 파일도 참조하지 않는다.

## 수정 범위 (엄수)
- 생성·수정 가능: `apps/2048/` 안의 위 4개 파일뿐.
- 그 외 모든 파일은 수정하지 않는다. 특히 `index.html`(블로그 메인), `css/`, `js/`, `posts/`, `CLAUDE.md`, `spec.md`, `.claude/`를 건드리지 않는다.
- 파일 삭제, git 명령 실행을 하지 않는다. (커밋은 Embed 단계에서 따로 한다.)
- 로컬 서버 실행이나 브라우저 검증은 하지 않는다. 검증은 별도 Review 에이전트가 한다. 단, 문법 오류를 줄이기 위해 코드를 다시 읽어 점검하는 것은 한다.
